# Privacy Policy

This application is a technical assessment project built by an individual developer.

## Data Collection
This app uses LinkedIn OAuth 2.0 to authenticate users and retrieve basic profile information such as:
- First name
- Last name
- Headline
- Email address (if permitted)

## Data Usage
The collected data is used only for:
- User authentication
- Displaying profile information
- Generating LinkedIn post content
- Publishing posts on behalf of the user (with explicit consent)

## Data Storage
Access tokens and user preferences are stored securely and are not shared with third parties.

## Data Sharing
This application does not sell or share user data with any third party.

## User Control
Users can revoke access at any time from their LinkedIn account settings.
